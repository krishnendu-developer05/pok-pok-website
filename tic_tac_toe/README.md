# Pok-Pok Tic Tac Toe

A premium, modern, ultra-smooth Tic Tac Toe web game built with a minimalist dark aesthetic, interactive glassmorphism, floating background glows, keyboard accessibility, zero input lag, and a perfect Minimax AI engine.

## 🛠️ Tech Stack
- **Structure**: HTML5 with semantic layout.
- **Styling**: Tailwind CSS via CDN + Custom CSS (`styles.css`) for fine-grained animations and visual styles.
- **Logic**: Vanilla ES6 JavaScript (`script.js`) with Web Audio API sound synthesis.

## 🚀 Features
- **AI Mode**: Toggle between **Easy** (random) and **Impossible** (Minimax) play.
- **Local Mode**: 2-player pass-and-play game mode.
- **Synthesized Sounds**: Sound effects generated programmatically (zero-latency click, sweep, win, and tie).
- **Smooth Animations**: GPU-accelerated scaling, turn sliding indicator, scoreboard bump, and SVG line draw animations.
- **Accessibility**: Arrow key navigation on the grid and Space/Enter key selection.

## 🎮 How to Play
1. Double-click the **Restart Round** button to reset the scoreboard.
2. Single-click the **Restart Round** button to reset the grid while maintaining the score.
3. Open `index.html` directly in any web browser to play.
